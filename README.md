## Introduction
"Student Data Management" is a python application which is used to classify students according to their grades<br>
Current the project supports the marks of one subject according to Marking scheme of SPPU(2019 Pattern)<br>
The purpose of this project to automate the data entry process and reduce the load on faculty<br>
NumPy,Pandas and Tkinter are used to manipulate data and provide a UI for teachers <br>

## Features
1.Classifies student data according to <a href="https://campus.unipune.ac.in/CBCS/CBCS_Regulations_for_SPPU_01.09.2018_29.09.2018.pdf">SPPU grading system</a><br>
2.Creates seperate spread sheets according to branches of students
3.Stores a list of emails of failed students (<a href="https://github.com/Neevs1/student-data-management/commit/3d6776393491804358aa88aa57ee2427688dde18">Added on 20/12</a>)
